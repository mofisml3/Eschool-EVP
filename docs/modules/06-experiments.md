# 06 — Module: Interactive Learning Experiments
## التجارب التفاعلية

The third stop in the narrative arc. Its purpose is to demonstrate **pedagogical innovation** — that the program goes beyond passive video and offers virtual labs, simulations, and gamified learning at national scale.

---

## 2. الأقسام (Page Sections, in render order)

1. **شريط الترحيب** — page hero + period filter + discipline filter.
2. **مؤشرات المكتبة الكبرى** — 5 KPI tiles (experiments, disciplines, avg interaction, monthly interactions, completion rate).
3. **التغطية حسب التخصصات** — 7-discipline grid with experiment counts.
4. **أنواع التجارب** — type breakdown (virtual labs, simulations, gamified, 3D visualizations).
5. **تجارب مختارة** — featured-experiments gallery (5–6 sample cards).
6. **اتجاه التفاعل الشهري** — 12-month interactions trend line chart.
7. **التوزيع حسب المرحلة** — stage breakdown (primary/middle/secondary).
8. **الإجراء التالي** — narrative-arc CTA: "الانتقال إلى المعلمين والأداء الأكاديمي".

## 8. ملاحظات الترحيل (Migration Notes — Static / API / CMS)

| Field | MVP source | Phase 2 destination | Reason |
|-------|------------|---------------------|--------|
| `heroKpis[*].value` | static seed | **API** | Live metrics |
| `disciplines[*]` | static seed | **API + CMS** | Counts from API; names from shared taxonomy |
| `typeBreakdown[*]` | static | **API** | Aggregation over experiment metadata |
| `stageBreakdown[*]` | static | **API** | Aggregation |
| `featuredRef` data | static seed | **CMS** | Editorial selection — must be human-curated |
| `interactionsTrendRef` | static 12-point series | **API** | Time-series store |
| Experiment metadata (titles, durations, thumbnails, preview URLs) | static seed | **CMS / LMS** | Content lives in the operational LMS |

**Rule of thumb for this module:**
- Same as videos: **featured experiments are editorial**, **trends and counts are computed**.
- The discipline taxonomy is shared with Teachers and Assessments — single source of truth.
