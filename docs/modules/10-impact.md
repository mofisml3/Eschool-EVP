# 10 — Module: Strategic Impact & Value
## الأثر الاستراتيجي والقيمة

The seventh stop in the narrative arc — and the **strategic conviction** chapter. Its purpose is to translate the program's operational scale into strategic meaning: alignment with Vision 2030, contribution to SDG 4, equity gains, social value, and international positioning. This is the page a Minister or a UNESCO delegate is most likely to cite back.

## 8. ملاحظات الترحيل (Migration Notes — Static / API / CMS)

| Field | MVP source | Phase 2 destination | Reason |
|-------|------------|---------------------|--------|
| `heroKpis[*].value` | static seed | **mostly CMS** | These are policy-defined, not measured |
| `vision2030Pillars[*]` | static | **CMS** | Editorial content, reviewed annually |
| `sdg4Targets[*]` | static | **CMS** | Status updated after each strategic review |
| `equity.urbanRuralGapReductionPercent` | static | **API** (computed from coverage data) | Quantitative, recomputed from operational data |
| `equity.regionsCoveredPercent / schoolsReached` | static | **API** | Cross-references overview module |
| `economicValue.*` | static | **annual report + CMS** | Tied to the annual economic evaluation |
| `internationalPositioning.*` | static | **CMS** | References external reports, updated when published |
| `milestones[*]` | static | **CMS** | Timeline updated as milestones are reached |
| `roadmap[*]` | static | **CMS** | Reviewed quarterly |

**Rule of thumb for this module:**
- **Most of this page is editorial**, not metric. It belongs in a CMS so non-developers can update it after each strategic review without touching code.
- The few quantitative fields (cost reduction, gap reduction) come from a documented annual evaluation — they should be tagged with `lastEvaluatedAt` so the UI can show the source date.
- Vision 2030 and SDG 4 mappings are the most cited content — version-control them carefully.
