# 07 — Module: Teachers & Academic Delivery
## المعلمون والأداء الأكاديمي

The fourth stop in the narrative arc. Its purpose is to demonstrate **the human capacity behind the program** — the breadth, depth, and professionalism of the teaching workforce that produces content and supports learners.

## 2. الأقسام (Page Sections, in render order)

1. **شريط الترحيب** — page hero + period filter + region/stage filters.
2. **مؤشرات الكادر الكبرى** — 5 KPI tiles (active teachers, avg teaching hours, content authored, certified teachers, subjects served).
3. **التوزيع حسب المرحلة الدراسية** — horizontal bars: primary / middle / secondary.
4. **التوزيع حسب المواد الدراسية** — top-12 subjects by teacher count.
5. **التوزيع الجغرافي** — compact map of teachers per region.
6. **الإنتاج التعليمي** — content authored breakdown (lessons / experiments / assessments).
7. **اتجاه النشاط التدريسي** — 12-month teaching-hours trend.
8. **التطوير المهني** — professional development snapshot.
9. **مؤشرات الجودة** — peer review, satisfaction.
10. **الإجراء التالي** — narrative-arc CTA: "الانتقال إلى التقييم وتقدّم التعلّم".

## 8. ملاحظات الترحيل (Migration Notes — Static / API / CMS)

| Field | MVP source | Phase 2 destination | Reason |
|-------|------------|---------------------|--------|
| `heroKpis[*].value` | static seed | **API** (HR + LMS aggregations) | Live measured quantities |
| `stageBreakdown[*]` | static | **API** | Aggregation over teacher records |
| `subjectsBreakdownTop[*]` | static | **API** | Aggregation; relies on shared subject taxonomy |
| `regionalDistribution[*]` | static | **API** | Joins teacher records with region |
| `contentBreakdown.*` | static | **API** | Content metadata aggregations (also surfaces in videos/experiments/assessments modules) |
| `professionalDevelopment.*` | static | **API** (HR system) | Live training records |
| `qualityIndicators.*` | static | **API** | Aggregations from peer-review and satisfaction subsystems |
| `teachingHoursTrendRef` | static 12-point series | **API** | Time-series store |
| Subject taxonomy / region taxonomy | static config | **shared config service** | Must match other modules exactly |

**Rule of thumb for this module:**
- All teacher counts and quality scores → **API** (HR + LMS).
- Editorial framing (e.g., insight sentences) lives in `i18n/ar.json` or a CMS — never hardcoded.
- The same `subjectId` and `regionId` must be used here and in every other module.
