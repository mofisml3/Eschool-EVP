# 08 — Module: Assessment & Learning Progress
## التقييم وتقدّم التعلّم

The fifth stop in the narrative arc — and the centerpiece of "evidence of outcomes". Its purpose is to demonstrate that **the program is not only used, but produces measurable learning gains** across subjects, stages, and regions.

---

## 2. الأقسام (Page Sections, in render order)

1. **شريط الترحيب** — page hero + period filter + stage/subject/region filters.
2. **مؤشرات التعلّم الكبرى** — 5 KPI tiles (national mastery, monthly deliveries, library size, pass rate, year-over-year gain).
3. **الإتقان حسب المادة الدراسية** — horizontal bars across 10+ subjects.
4. **الإتقان حسب المرحلة الدراسية** — primary / middle / secondary.
5. **اتجاه الإتقان خلال العام الدراسي** — 12-month line chart with the program-wide mastery curve.
6. **توزيع نتائج المتعلمين** — distribution by performance band (excellent → did-not-pass).
7. **أنواع التقييمات** — formative / summative / diagnostic breakdown.
8. **تغطية المنهج بالأنشطة التقويمية** — % of curriculum units with at least one assessment.
9. **الإتقان حسب المنطقة** — regional mastery snapshot.
10. **الإجراء التالي** — narrative-arc CTA: "الانتقال إلى الدعم ورعاية الطلاب".

## 8. ملاحظات الترحيل (Migration Notes — Static / API / CMS)

| Field | MVP source | Phase 2 destination | Reason |
|-------|------------|---------------------|--------|
| `heroKpis[*].value` | static seed | **API** (assessment subsystem) | Live measured outcomes |
| `masteryBySubject[*]` | static | **API** (cached daily) | Heavy aggregation |
| `masteryByStage[*]` | static | **API** | Aggregation |
| `performanceDistribution[*]` | static | **API** | Histogram from assessment results |
| `assessmentTypes[*]` | static | **API** | Aggregation from assessment metadata |
| `curriculumCoverage.*` | static | **API + curriculum config** | Curriculum taxonomy lives in shared config |
| `regionalMasteryRef` | static (reuses regions.json) | **API** | Joins region + assessment |
| `yearMasteryTrendRef` | static 8-point series | **API** (time-series) | Recomputed monthly |
| Performance band thresholds | static config | **shared config service** | Policy-defined thresholds |
| Subject taxonomy | static config | **shared config service** | Must match other modules |

**Rule of thumb for this module:**
- Every percentage and count → **API**.
- Performance band thresholds (60/70/80/90) are policy → kept in a shared config so policy changes don't require code edits.
- The yearly mastery curve is the single most cited chart of the portal — its API contract should be locked early.
