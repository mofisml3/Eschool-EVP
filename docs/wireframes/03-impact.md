## 3. التخطيط — الجهاز اللوحي والجوال (Tablet & Mobile)

Same collapse strategy as Overview wireframe:
- Sidebar → icon-only on tablet, hamburger drawer on mobile.
- 4 hero KPIs: row of 4 → 2+2 (tablet) → 2+2 stacked (mobile).
- Two-column rows collapse to single-column in this order: Vision 2030 → SDG 4 → Equity → Economic value.
- Milestones timeline on mobile becomes a **vertical** stacked list with year labels on the inline-start side; the horizontal timeline does not work below 768px.
- Closing CTA always full-width.

---

## 4. الحالات (States)

| State | Behavior |
|-------|----------|
| Loading | Page-level shimmer; KPIs and cards reveal as data resolves. |
| Empty (alignment data missing) | "تخضع المواءمة الاستراتيجية للمراجعة الدورية…" inside the affected card; rest of page renders. |
| Error | Page-level banner with "إعادة المحاولة"; reuses shell error pattern. |
| Last-reviewed stale | If `lastReviewedAt` is older than 6 months, an amber footnote appears under the hero: "تخضع البيانات لمراجعة استراتيجية ربع سنوية." |

---

## 5. التفاعل (Interaction Notes)

- **No period filter** — strategic data is reviewed quarterly, not periodically.
- **No drill-downs** — every card is terminal.
- **"تحميل ملخص الأثر الاستراتيجي"** in the closing CTA links to the corresponding PDF in the Reports center.
- **SDG 4 chip click** → opens a methodology dialog with the alignment justification.
- **Milestone node click** → tooltip only in MVP (no detail page).
- **Keyboard order:** top bar → hero → KPIs → Vision pillars → SDG targets → equity → economic value → international positioning → milestones → roadmap → closing CTA → sidebar.
